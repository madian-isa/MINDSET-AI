# MINDSET AI

A multilingual AI chatbot that understands Bangla, English, and Banglish — powered by Google Gemini API with a secure Supabase Edge Function backend.

## Features
- Multilingual chat (Bangla / English / Banglish)
- Secure API key handling via Supabase Edge Function (no keys exposed in frontend)
- Dark, trading-terminal-inspired UI
- Chat history saved locally in the browser
- Daily-limit handling with direct Telegram support link

## Setup
1. Deploy the Supabase Edge Function (`gemini-chat`) with your `GEMINI_API_KEY` set as a secret.
2. Open the app, go to Settings, and enter your Supabase Project URL, Anon Key, and Edge Function URL.
